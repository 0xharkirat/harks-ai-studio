Customers do not read changelogs, but they do read a good story about their own problem. We write every release note in the same four steps.

## The four steps

1. Start with the problem a customer told us about.
2. Show the fix in one screenshot.
3. Add one sentence about how it works.
4. Link to the docs and stop.
