# TinaCMS ads: platform copy

Copy to paste into YouTube, LinkedIn and Meta, one block per film.
Files are in `out/deliver/`. Each film has an SRT file for captions (plain text, no styling).
The one idea: **TinaCMS puts a visual editor on top of the Markdown in your Git repo.**
Campaign line: **Edit your site. Visually.**
Tag: **Sites, Docs and Llamas. No Dramas.**

## Claims you can use

- Free and open source. (Do not name the licence: it is about to change.)
- 13.8k stars on GitHub (checked 2026-11-12: 13,871). Check the number again on the day you publish.
- Content in Markdown, MDX and JSON, stored in your own Git repo.
- Visual editing: click the page, edit it, see it live. Every edit is a commit.
- TypeScript schema and a GraphQL API.
- Works with Astro and Next.js (starters with visual editing), or bring your own: `tinacms init` adds Tina to Hugo, Jekyll or any other static site.
- One command to start: `npx create-tina-app@latest`.

Do not say:

- Customer names, logos or quotes. We have no permission for paid ads.
- Rankings such as "#1" or "leading".
- AI features in TinaCMS. They are not shipped. (Starting a project with your own AI agent is fine: the anthem's end card says it.)
- Prices, speed numbers or page counts.
- Hype words such as "revolutionary".

## Limits used in this file

These are typical limits. Check them in each ads tool before you launch.

| field | limit used |
|---|---|
| YouTube title | 70 characters or fewer (the hard limit is 100) |
| YouTube description | the first 2 lines show before "more", so the hook comes first |
| LinkedIn intro text | under 150 characters |
| LinkedIn headline | under 70 characters |
| Meta primary text | first line 125 characters or fewer (shows before "See more") |
| Meta headline | 40 characters or fewer |

One call to action in every ad: **Learn more**, pointing to `https://tina.io`.
Add UTM tags to the link as your analytics needs, for example `?utm_source=linkedin&utm_medium=paid_video&utm_campaign=edit-visually&utm_content=30s`.
